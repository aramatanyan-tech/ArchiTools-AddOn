# ArchiTools Add-On для Archicad

Аддон добавляет в Archicad меню **ArchiTools** с командами:

1. Нумерация выделенных зон
2. Нумерация зон по кликам (вкл/выкл)
3. Края зон не по линии стен и колонн
4. Слежение за исправлениями (вкл/выкл)
5. Снять подсветку и отметки
6. Двери и окна по помещениям
7. Проверка геометрии зон
8. Проверка номеров и названий зон
9. ТЭП и экспликация в Excel
10. Открыть окно ArchiTools

На любую команду можно назначить клавишу: Options > Work Environment > Keyboard Shortcuts.

Команды выполняет программа ArchiTools.exe. Если её окно открыто - команда уходит в него
мгновенно; если закрыто - аддон сам запускает программу.
Перед первым использованием один раз откройте ArchiTools.exe вручную.

Сборка: GitHub > вкладка Actions > «Build ArchiTools Add-On». Готовый файл -
в разделе Artifacts: ArchiTools-AddOn-Archicad-28 (внутри ArchiTools.apx).
